# Сервис генерации WebP-миниатюр товаров

Усачев Тимур, группа 5130904/40102. СМО, вариант 1. Первичные артефакты проектирования.

Модель описывает обработку заданий на создание миниатюр товаров 800×800 WebP. Источники — активные экземпляры сервиса загрузки товаров, массового импорта и административной CMS. Приборы — вычислительные узлы IMG-1 … IMG-M. При занятости всех узлов задания ожидают в общем буфере; при переполнении вытесняется задание под указателем.

## Вариант

`ИБ | ИЗ1 | ПЗ2 | Д10З1 | Д10О1 | Д2П1 | Д2Б1 | ОР2 | ОД1`

| Код | Смысл |
|---|---|
| ИБ | N бесконечных источников, продолжающих генерацию независимо от состояния своих предыдущих заявок |
| ИЗ1 | Пуассоновский поток каждого источника; интервалы между поступлениями имеют экспоненциальное распределение с параметром λi |
| ПЗ2 | Время обслуживания равномерно распределено на [tmin; tmax] |
| Д10З1 | Поиск свободной ячейки от указателя по кольцу; после записи указатель переходит на следующую ячейку |
| Д10О1 | При полном буфере вытесняется ожидающая заявка под указателем; её место занимает новая |
| Д2П1 | Поиск свободного прибора с начала списка по возрастанию номера |
| Д2Б1 | FIFO — выбор самой старой из оставшихся в буфере заявок |
| ОР2 | Графики показателей по результатам серии экспериментов |
| ОД1 | Календарь событий, содержимое буфера, указатель, состояния приборов и текущие показатели |
